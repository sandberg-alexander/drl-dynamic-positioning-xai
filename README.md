# DRL-DYNAMIC-POSITIONING-XAI

This is the repository for the paper "Deep Reinforcement Learning for Ship Dynamic Positioning: A Live Explainable AI Approach on an Autonomous Ferry Prototype" and the master's thesis "Deploying Trustworthy Deep Reinforcement Learning for Dynamic Positioning: A Real-time Explainable AI Approach on Real Maritime Cyber-Physical Systems", course TTK4900, Cybernetics and Robotics @ NTNU.

- Author: Alexander Sandberg

- Email: **alexander@sandberg-oslo.no**

The paper is available at: **{link}**

The master's thesis is available at: https://nva.sikt.no/registration/019a1506973c-03176847-b705-4208-9048-5069284d9c61

The repository includes 
1. project_mAXAI - the project that run the project mAXAI code, including training, evaluating & deploying/testing for DRL and SHAP based exblainability dashboard for XAI
2. local_env - where collected data is used to analyse and generate plots and testing scripts are made
3. data - the environments, trained models and their data, including evaluations, monitorings and runs
